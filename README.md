# ASAL BeautyCare System 

A comprehensive database-driven desktop application for managing an online beauty store (skincare & makeup). Built with Java and MySQL.

## Features
- Product & category management (Skincare, Makeup, Fragrance, Tools)
- Customer order tracking and invoicing
- Supplier & purchase order management
- Inventory tracking with automatic stock updates after sales
- Payment recording for sales and purchases
- Delivery status tracking
- Customer return handling
- Analytical reports (top-selling products, monthly sales, low stock alerts)
- Data archiving for old records

## Tech Stack
- **Language:** Java
- **Database:** MySQL
- **UI:** JavaFX
